# 个人思考

这个项目保存 Jayce 对 AI 产品、个人智能、知识与经验沉淀、跨 Agent 上下文及创业方向的长期思考。

## 当前主线

从“第二大脑 / 个人知识库”继续向下追问：当基础模型、检索、记忆和 Agent harness 不断增强时，哪些用户资产仍应独立存在，并能随着模型增强而增值？

当前形成的方向是：从保存 Information，走向可迁移的 Personal Intelligence，包括 Memory、Procedure、Judgment、Eval 与 Agency；产品切入口暂时收束为 Cross-Agent Context，再逐步进入 Expertise Compiler / Expertise Network。
