# 个人思考：当前上下文

更新时间：2026-09-14

## 当前命题

传统“第二大脑”侧重收集、关联和召回信息；随着检索、记忆和 Agent runtime 成为平台能力，单独售卖这些结构的价值会下降。仍然稀缺的是用户独有的经历、判断、修正轨迹、结果反馈、权限与目标。

当前方向因此从 Personal Knowledge Base 转向 **Personal Intelligence Layer**：模型可以替换，但用户的长期状态应可拥有、迁移、审查和撤销，并能被不同 Agent 按需调用。

## 已形成的判断

- 补偿模型能力不足的复杂结构容易随模型升级贬值；表达用户独特性、现实约束和评价标准的结构会随模型增强而增值。
- 信息重要，但“主动收藏”不是完整产品；真实工作过程、用户对 AI 输出的接受、拒绝、修改、决策理由和后续结果信号更强。
- 高价值 Judgment 应带有场景、理由、案例、反例、置信度、时效、来源与 outcome。
- Skill 的重点可能从固定步骤转向目标、原则、约束、案例、工具和评价标准。
- 产品应通过 Model Improvement Test：下一代模型更强时，产品应获得更大杠杆。

## 产品方向

核心循环：Capture → Understand → Reuse → Accumulate → Transfer。

1. Cross-Agent Context：不同 Agent 不必分别重新认识用户。
2. Personal Intelligence：从长期使用中形成 Experience、Judgment 与 Personalized Eval。
3. Expertise Network：把经过验证的个人能力授权给团队或他人调用。

MVP 暂定为轻量 Desktop / Web Home + Browser Capture + MCP/API。Home 是查看、修正、授权和撤销的控制面板；主要价值发生在用户原本使用的 Agent 中。

## 尚未决定

- 首批用户和一个足够窄的高频决策场景。
- 首次、7 天和 30 天的可测量价值。
- 数据自动捕获边界、隐私、权限、删除与撤销机制。
- Judgment schema 以及跨 Agent 的首个接入方式。
- 如何避免产品只成为平台 Memory 的一个功能。
- Expertise Package 的效果评价与商业演进顺序。
